# IAASSE Member Conversion Prediction

A machine learning project focused on predicting student conversion to paid membership using engagement and activity data.

## Project Overview

The goal of this project is to analyze membership-related behavior and identify patterns that may help predict whether a student will become a paid member.

## Dataset

The dataset includes features related to student activity and engagement, such as:

- Login frequency
- Event attendance
- Completed courses
- Engagement score
- Email clicks
- Referral source
- Membership duration

**Note:** The current dataset is synthetic and is used for learning, experimentation, and model development.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Scikit-learn

## Machine Learning Approach

This project focuses on binary classification. The following models are planned for exploration and comparison:

- Logistic Regression
- Decision Tree
- Random Forest

Model performance will be evaluated using appropriate classification metrics, including precision, recall, and F1-score.

## Project Goals

- Explore and prepare the dataset.
- Identify features related to membership conversion.
- Train and compare classification models.
- Evaluate model performance.
- Derive insights that may support membership engagement strategies.

## Project Status

**In Progress** — Data exploration, preprocessing, and model development are ongoing.

## Disclaimer

This is an educational project. Predictions and findings based on synthetic data should not be interpreted as evidence of actual IAASSE member behavior.
